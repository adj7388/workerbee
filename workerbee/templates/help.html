This app find words using the same approach as the New York Times Spelling Bee game. For now there are two things you can do here:

Find Words: enter letters à la Spelling Bee and the app uses those letters to look for words in a single word list of your choice. One advantage of Find Words is that you can download the resulting words.

Show Summaries: similar to Find Words, except that it searches all word lists in one go, and displays a summary of what it finds in each list, optionally including the words from each list.

Find Words — what the controls do

Use Word List

Choose the word list in which to search for words. If you don't know which one to use, just accept the default. Or try different ones and see the difference.

What the heck are word lists? See the About page.

Required Letter and Other Letters

These fields mimic Spelling Bee. The yellow letter in the middle of the Spelling Bee page is the letter that is "required" in each word you find. Enter only one letter in this field.

On the Spelling Bee page that yellow, required letter is surrounded by six other letters. Valid Spelling Bee words have at least four letters and include the required letter and one or more of these "other" letters. Enter exactly six letters in this field.

How to group results

The grouping options mimic those found on the Spelling Bee hints page and in Spelling Bee Buddy (another hint application provided by Spelling Bee).

The options are pretty self-explanatory.

  • Group by initial letters
    Note: this is the first two letters, not just the 'initial'
  • Group by word length
  • No grouping — just an alphabetical list

Link to definitions

Each word is linked to its definition in an online dictionary. Choose your preferred dictionary here. This is handy for looking up words you don't know.

Show Summaries — what the controls do

Word Lists

All the word lists supported by the app are displayed here. A summary of results will be presented for each of these word lists. Again, see the About page for more information about word lists.

Required Letter and Other Letters

Same as Find Words above.

Sort summaries by number of words

Summaries are always sorted by the number of words found in each word list. You can choose whether the sort is ascending or descending.

Include all words in summaries

Summaries include the number of words found, all the pangrams, etc. from that list. Check this box to also include all the words found in each word list. This results in a busier display but, depending on what you're doing, it can be quite useful.

Ascending / Descending

When you select Include all words, choose one of these options to sort the words alphabetically or by word length.
