This app find words using the same approach as the New York Times Spelling Bee game.

Find Words: enter letters à la Spelling Bee and the app uses those letters to find words in a single word list you choose. An advantage of Find Words is that you can download the resulting words.

Show Summaries: similar to Find Words, except that it searches all word lists and displays a summary of what it finds in each, optionally with all words found in each list.

For more detail, see the About page.

Find Words — what the controls do

Use Word List

Choose the word list to use to find words. If you don't know which one to use, just accept the default. Or try different ones and see the difference.

Required Letter

The yellow letter in the middle of the Spelling Bee game is required, meaning it must be present in every word found.

Other letters

On the Spelling Bee page the yellow required letter is surrounded by six other letters. These letters are used in addition to the required letter to form words.

How to group results

The grouping options mimic those found on the Spelling Bee hints page and in Spelling Bee Buddy (another hint application provided by Spelling Bee).

The options are pretty self-explanatory.

  • Group by initial letters
  • Group by word length
  • No grouping — just an alphabetical list

Link to definitions

It's nice to be able to look up in a dictionary the words you don't know. This dropdown allows you to choose which online dictionary and the app will link all the words it finds to the definition in that dictionary.

Show Summaries — what the controls do

Word Lists

All the word lists supported by the app are displayed here. A summary of results will be presented for each of these word lists.

Required Letter and Other Letters

Same as Find Words. See above.

Sort summaries by number of words

The summaries are always sorted by the number of words found in each word list. You can choose whether the sort is ascending or descending.

Include all words in summaries

Normally, a summary includes just the word list, the number of words found, all the pangrams, etc. But you can check this box to also display all the words found in each word list.

When you select "Include all words", you cand choose to sort the words alphabetically or by word length.

Each word will be linked to an online dictionary. You can choose your preferred dictionary using the "Link words to" dropdown.
